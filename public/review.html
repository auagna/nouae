제품 판단

nou ae는 현재 “개인 일정 + 프로젝트 대시보드 + 일일 운영 시스템”의 뼈대를 갖췄습니다. 다음 성장은 기능 개수보다 화면 간 연결성을 높이는 쪽이 중요합니다. 특히 Today, Calendar, Review가 하나의 실행 루프로 더 자연스럽게 이어져야 합니다.

구현 리뷰

잘 잡힌 부분

  • 팀/협업 기능 없이 개인 운영 시스템이라는 방향을 유지했습니다.
  • localStorage 저장 계층을 별도로 두어 나중에 백엔드로 교체하기 쉽습니다.
  • Today 실행 플로우가 v2.1에서 실제 사용 가능한 수준으로 강해졌습니다.
  • selector 계층이 생겨 화면별 통계 계산 중복이 줄었습니다.

보강이 필요한 부분

  • Calendar의 Day/Week 화면은 아직 시간축 경험이 약합니다.
  • Project 상세는 목표, 로그, 다음 행동이 더 분리되어야 합니다.
  • Review는 아직 다음 계획을 자동으로 생성하는 힘이 부족합니다.
  • 남아 있는 화면의 한글 카피와 빈 상태를 더 정리해야 합니다.

버전 히스토리

v1.0.0

첫 MVP. 앱 shell, 주요 화면, localStorage, seed data, JSON export/import를 구축했습니다.

v2.0.0

운영 지표, selector 계층, Inbox 필터, Calendar 요약, Project 진행률, Review 7일 요약을 추가했습니다.

v2.1.0

Today 실행 플로우를 강화했습니다. 프로젝트 연결, 상태 버튼, 블록 시작, Review 이동 액션이 들어갔습니다.
